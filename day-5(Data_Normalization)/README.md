# Day 5 – Databases, Normalisation and Data Definition

This folder contains the Day 5 database assignments completed during
Hexaware training. The assignments cover database fundamentals,
normalisation, table and collection management, constraints, and data
manipulation.

## Assignments

### Set 1 – Retail Inventory and Product Reviews

| File               | Description                                                            |
|--------------------|------------------------------------------------------------------------|
| `MS_SQL_QUERY.sql` | Database schema, tables, constraints, sample data, and SQL operations. |
| `collections.js`   | MongoDB collections, document validation, and operations.              |

### Set 2 – Bank Branch Accounts and Customer Activity

| File               | Description                                                            |
|--------------------|------------------------------------------------------------------------|
| `Ms_sql_query.sql` | Database schema, tables, constraints, sample data, and SQL operations. |
| `collections.js`   | Customer activity collection and MongoDB queries.                      |

### Set 3 – Hospital Patient Records and Clinical Notes

| File               | Description                                                                 |
|--------------------|-----------------------------------------------------------------------------|
| `ms_sql_query.sql` | Patient, doctor, department, visit, and billing tables with SQL operations. |
| `collections.js`   | Clinical notes collection, validation, and queries.                         |

## Technologies and Tools

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- MongoDB
- MongoDB Compass
- Mongosh
