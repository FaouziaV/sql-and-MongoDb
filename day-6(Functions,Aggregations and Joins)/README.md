# Day 6 – Functions, Aggregation, Grouping and Joins

This folder contains the Day 6 database assignments completed during
Hexaware training. The assignments cover SQL functions, aggregate
functions, `GROUP BY`, `HAVING`, joins, and MongoDB aggregation.

## Assignments

### Set 1 – Retail Sales Reporting

| File               | Description                                                                        |
|--------------------|------------------------------------------------------------------------------------|
| `ms_sql_query.sql` | Eight SQL sales reports and examples using SQL functions, joins, and aggregations. |
| `reports.js`       | MongoDB aggregation pipelines for sales reporting.                                 |

### Set 2 – Insurance Policy Reporting

| File          | Description                                           |
|---------------|-------------------------------------------------------|
| `reports.sql` | Policy, premium, customer, claims, and agent reports. |
| `reports.js`  | MongoDB claims-notes aggregation pipelines.           |

### Set 3 – Telecom Usage and Billing Reporting

| File          | Description                                                             |
|---------------|-------------------------------------------------------------------------|
| `reports.sql` | Telecom usage, call minutes, invoices, revenue, and subscriber reports. |
| `reports.js`  | MongoDB usage-event aggregation pipelines.                              |

## Technologies and Tools

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- MongoDB
- MongoDB Compass
- Mongosh
